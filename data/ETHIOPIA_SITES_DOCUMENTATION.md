# Ethiopia Off-Grid Solar Sites: Data Documentation

This document provides detailed provenance for each of the 50 validated site locations used in the QEnergic microgrid optimization model. Data is derived from Ethiopia's National Electrification Program (NEP 2.0), DREAM Agricultural Mini-grid Pilots, World Bank feasibility studies, and AfDB/IOM settlement surveys.

## Data Sources Summary

### Primary Sources

| Source | Citation | Data Used |
|--------|----------|-----------|
| **NEP 2.0** | Ethiopia National Electrification Program 2.0 (2019-2025) | Universal access targets, 35% off-grid designation, priority sites |
| **DREAM Project** | Distributed Renewable Energy-Agriculture Modalities Pilot, World Bank/ESMAP | Huluku, Moko, Chefe Kora site specifications, irrigation load profiles |
| **EEU 25 Mini-Grids Tender** | Ethiopian Electric Utility / African Development Bank | Omorate, Tum, Maji system sizes and operational data |
| **NASA POWER** | NASA Prediction of Worldwide Energy Resources | Site-specific GHI values, seasonal variance data |
| **UNHCR/IOM** | UN Refugee Agency and International Organization for Migration | Dollo Ado, Pugnido, Sherkole camp population data |
| **World Bank MTF** | Multi-Tier Framework for Household Energy Access | Tier 1-5 classification, consumption per capita estimates |

### Solar Irradiance Methodology

GHI values assigned using:
1. NASA POWER database satellite-derived estimates
2. Ground station validation where available (Addis Ababa, Dire Dawa)
3. Regional climate zone adjustments:
   - Afar/Somali arid zones: +0.3-0.5 kWh/m²/day above national mean
   - Western highlands (Kiremt wet season): -0.5-0.8 kWh/m²/day below national mean
4. "Worst-month" design conservatism for off-grid reliability

### Cost Estimation Methodology

Installation costs derived from:
1. **Base cost**: $600-$1,500 per connection (World Bank Africa mini-grid benchmark)
2. **Logistics coefficient**: Distance from Addis Ababa–Djibouti corridor
   - Central Oromia: ~$800/connection
   - Remote periphery: ~$1,000-$1,200/connection
3. **Technology type**: Mesh-grid sites (Gomi, Telifa) use ~$550/connection baseline
4. **Security premium**: Afar, Gambella, Somali border zones +20-30%
